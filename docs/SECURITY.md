# FOMS 安全与数据处理基线

## 禁止提交到 Git
- 真实客户个人信息、客户合同和报价。
- 完整运单号、收发货人联系方式和详细地址。
- 生产数据库导出、真实附件和员工敏感信息。
- API Key、密码、JWT secret、私钥、证书和真实 .env。
- 未经公司批准的内部制度或商业机密。

## 权限
- 后端必须执行身份验证、角色权限和数据范围过滤。
- 普通员工只能访问本人记录。
- 公司管理层默认只读已发布报告。
- 系统管理员不自动获得业务数据访问权。
- 文件下载必须再次校验关联业务记录的访问权限。

## AI
- 只允许调用经公司批准的模型供应商。
- API Key 仅保存在服务端密钥配置中。
- 调用前按字段白名单脱敏。
- 不发送客户姓名、联系方式、完整运单号、详细地址及未经授权商业机密。
- AI 输出必须视为不可信内容，经过结构验证和人工审核。
- AI 不得直接写入或修改原始业务记录。

## 文件上传
- 限制文件扩展名、MIME、大小和解析资源。
- 对上传文件使用随机存储键，不使用用户文件名作为路径。
- 文件存储在非公开桶/目录，通过后端授权下载。
- Excel 解析应限制行数、工作表数和执行资源，防止恶意文件造成拒绝服务。

## 公开仓库
当前仓库为 Public。只提交通用需求和不含敏感信息的代码。部署前需由公司确认哪些设计文档可公开。
